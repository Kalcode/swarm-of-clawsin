# Audio credits

Swarm World's sound is all synthesized at runtime by `web/sound.js` with the Web Audio API (noise, oscillators and
envelopes). No audio files are shipped, so there is nothing to attribute and no third-party license applies.

Kenney's CC0 audio packs (https://kenney.nl/assets, category audio) were considered for samples, but the site refuses
automated downloads, so none were fetched. If recorded samples are added here later, list each pack with its author,
URL and license (CC0 only) in this file.
